Datenschutz

Diese Anwendung ist ein privates Projekt und wird nur vom Betreiber selbst genutzt.

Nach ausdrücklicher Anmeldung greift sie nur auf die eigene Google-Tabelle und die eigene Google-Tasks-Liste des Betreibers zu, um einen Wochenplan und eine Einkaufsliste zu speichern. Daten werden nicht verkauft, nicht für Werbung genutzt und nicht an Dritte weitergegeben.

Diese Webseite erhebt selbst keine Daten und setzt keine eigenen Cookies. Sie wird über GitHub Pages bereitgestellt; GitHub kann beim Aufruf technische Zugriffsdaten verarbeiten.
